# Лабораторная работа № 2 — вариант 2

**Дискретная математика (неклассические логики)**  
Тема: «Интерпретатор многозначных логик и проверка семантических свойств формул».

Консольный интерпретатор формул логики высказываний для **классической логики**, сильной трёхзначной логики **Клини (K3)** и трёхзначной логики **Лукасевича (L3)**. Реализованы полный перебор оценок, таблицы истинности, проверка общезначимости, выполнимости, тождественной ложности, сравнение логик и семантическое следование.

## Установка и запуск

Требуется **Python 3.10+**. Проект можно открыть в PyCharm командой **File → Open**, выбрав папку `DiscreteMath_Lab2_Variant2`. Рабочая директория при запуске `main.py` должна быть корнем проекта; прямой запуск через абсолютный путь также поддерживается.

В терминале PyCharm:

```bash
python -m pip install -r requirements.txt
python main.py
```

Для проверки:

```bash
python -m pytest -q
python main.py --variant2
python main.py --export-results
```

На macOS/Linux при необходимости замените `python` на `python3`, на Windows также можно использовать `py`.

Основное приложение использует только стандартную библиотеку; **pytest** требуется для автоматических тестов.

## Режимы программы

| Пункт | Действие |

Для возврата при вводе: `:back`; для полного выхода из любого меню: `:exit`.

Примеры пакетного запуска:

```bash
python main.py --formula "p -> q -> (q -> q)"
python main.py --analyze "p -> p" --logic k3
python main.py --logic l3 --premise "p -> !q" --premise "!q -> r" --entails "!p | r"
python main.py --variant2
```

## Правила формул

Поддерживаются операции `¬` (`!`), `∧` (`&`), `∨` (`|`), `→` (`->`), переменные и круглые скобки. Переменная `v` **не** считается оператором дизъюнкции. Приоритеты: **¬ > ∧ > ∨ > →**; бинарные операции одного приоритета связываются **слева**.

По замечанию преподавателя из первой лабораторной:

- `p -> q -> r` = `(p -> q) -> r`;
- `p -> (q -> r)` — иная структура;
- `p -> q -> (q -> q)` = `(p -> q) -> (q -> q)`.

Порядок приоритетов — принятое соглашение интерфейса, а не отдельное указание методички. Проверка экземпляров аксиоматических схем вынесена в `logic/schemas.py`; она **не заменяет** проверку семантических свойств.

В трёхзначных логиках вводятся `0`, `1/2` или `1` (варианты `0.5` и `½` поддерживаются). Во внутреннем представлении используются коды **0, 1, 2** для значений **0, 1/2, 1** соответственно; пользовательское `1` всегда означает истину.

Общезначимость и выполнимость определяются относительно выделенного значения **1**. Невыполнимость не тождественна значению 0 на всех оценках. Следование означает отсутствие оценки, где все посылки равны 1, а заключение не равно 1. Отсутствие совместных моделей посылок сообщается отдельно.

## Результаты варианта 2

| Формула | Классическая: общезначима | K3 | L3 |
|---|---|---|---|
| F1: `!!p -> p` | да | нет | да |
| F2: `(p \| !p) -> q` | нет | нет | нет |
| F3: `(p -> q) & (q -> p)` | нет | нет | нет |
| F4: `p & !p` | нет | нет | нет |
| F5: `((p & q) -> r) -> (p -> (q -> r))` | да | нет | да |

F4 невыполнима во всех трёх логиках, тождественно ложна только в классической.

| Следование | Классическая | K3 | L3 |
|---|---|---|---|
| R1 | следует | следует | следует |
| R2 | следует | следует | не следует |
| R3 | следует | не следует | следует |
| R4 | не следует | не следует | не следует |

Полные таблицы истинности (15 CSV), расчёты отношений, значения всех посылок в контрпримерах и машиночитаемые результаты находятся в `results/variant2/`. Академический отчёт — в `report/` (DOCX и PDF).

## Проверка и ограничения

Полный регрессионный набор на Python 3.13.5 / pytest 9.0.2: **324 passed in 46.92s**. Отдельно воспроизведены результаты `--variant2`. Ранее выполнен независимый стресс-прогон 50 000 корректных формул, 10 000 некорректных строк и 3 000 задач на следование; методика и выводы — в `qa/QA_REPORT.md`.

Дополнительный стресс-прогон:

```bash
python -m qa.stress --formulas 50000 --invalid 10000 --relations 3000
```

Установлены защитные пределы: 20 000 символов, 8192 токена, 4096 узлов AST, 128 уровней вложения; стандартный предел перебора — 100 000 оценок и 3 000 000 шагов вычисления. При превышении полного перебора результат **не объявляется доказанным**.

Случайные тесты и программные испытания не заменяют математического доказательства абсолютной корректности для всех возможных формул.
